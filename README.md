Solmar Bay is a complete open-world crime game: explore a sun-soaked fictional coastal city on foot or by car, steal cars, dodge the police across a 0–5 star wanted system, run 8 story missions for the fixer Rosa Delgado, work taxi fares, collect 24 hidden coins, and fight your way through shootouts — all in vanilla JavaScript and Canvas, with procedural sound and a day/night cycle.

## Run it

```sh
python3 -m http.server 8080 --directory game  (then open http://localhost:8080)
```
